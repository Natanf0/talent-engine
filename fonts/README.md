Os arquivos TTF foram copiados sem modificações das fontes instaladas fornecidas pelo ambiente do projeto. Ambos são incorporados aos PDFs; nenhuma fonte de marca depende da instalação de fontes no sistema ou de downloads em execução. A fonte PDF padrão Symbol é usada apenas para a seta dos links, ausente nessas duas fontes.
